# 智遇 演示视频录制方案

## 录制环境

- 浏览器：Chrome 无痕窗口（清除 localStorage）
- 屏幕：16:9，建议 1920×1080
- 录音：清晰麦克风
- 网络：确保能访问 dinozone.asia

## 录制要点

1. **不要滚动太快**——每个模块停留 2-3 秒让观众看清
2. **InboxSim 是高潮**——这部分给足时间，展示消息到达动画、回复交互、侧边栏细节
3. **HR 端重点展示"不是通用工具，而是有AI分析深度"**
4. **结尾点题**——"展示真实的你，而不只是一份简历"
5. **全程用鼠标**，不要用键盘快捷键（观众看不到键盘）

## 时间分配

| 段落 | 时长 |
|------|------|
| 首页 + 岗位详情 | 2 分钟 |
| InboxSim | 3 分钟 |
| AI报告 + 投递 | 1.5 分钟 |
| HR仪表盘 + 候选人列表 | 1.5 分钟 |
| 候选人报告（5个Tab） | 3 分钟 |
| 收尾 | 30 秒 |
| **总计** | **约 11.5 分钟** |
